# Mehndi Invitation Card

A single-page, mobile-first animated Mehndi invitation (`index.html`). There's no build step and no dependencies apart from Google Fonts.

Open `index.html` in a browser, or host it on any static host (GitHub Pages, Netlify, Vercel), and share the link.

## Customise
Everything on the card comes from the `CONFIG` object near the bottom of `index.html`:
names, city, main event date/time (drives the scratch-reveal date and countdown), hosts and contacts,
the guest letter, the events list (Dholki / Mayun / Mehndi Night), FAQ, WhatsApp RSVP number and an optional couple photo.

## Flow
1. A curtain of marigold strands parts when tapped, and the dholak music starts.
2. Bismillah and the couple's names.
3. Hosts: bride's side and groom's side tabs, with tap-to-call buttons.
4. "Dear Guests" letter.
5. Scratch the henna arch to reveal the date. Petals burst, and a live countdown runs underneath.
6. One screen per event, with a map link, an .ics calendar download and tap-to-shower petals.
7. The couple (monogram, or the photo if one is set).
8. FAQ accordion.
9. Finale: light a floating diya, or RSVP on WhatsApp.
